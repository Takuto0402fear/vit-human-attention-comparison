# Figure audit -- LAU-conference paper figures

Generated by `scripts/paper_figures/` (see that directory's `README.md` for
usage). This audit records data provenance, methodology, deviations from
existing figures, and verification results for Figures 1-3 and the
Appendix figures. No raw data, existing results, or existing plotting
script was modified or overwritten while producing these figures; no new
model inference, probe training, or attention extraction was run.

Terminology note: what earlier internal reports and code call the
"M-shape" / `M_contrast` is referred to as the **"N-shape profile"** in all
figure captions and this audit, per the paper's terminology. Internal
variable names such as `M_contrast` / `m_contrast` in the existing
codebase and CSVs (e.g. `outputs/model_comparison_statistics/
m_contrast_summary.csv`) were left unchanged, as instructed. No figure or
caption in this set uses causal language (e.g. "image-language contrastive
learning produced/caused the N-shape"); all describe it as an observed
layer-wise profile in CLIP.

## 3. Aggregation / CI / correlation methodology

- **Figures 1, 2(a), Appendix 1-3**: mean +/- 95% CI computed by
  image-ID-level bootstrap resampling (`common.bootstrap_mean_ci`):
  seed=42, n_boot=10000, percentile CI (alpha=0.05), applied independently
  per model to that model's own 700-image, 12-layer matrix. This method
  was chosen (rather than reusing each model's pre-existing `_std` column
  in `outputs/model_comparison_layerwise/comparison_values.csv`) because
  those pre-existing `std` columns are **not** on a common footing across
  models: DeiT/SL's `NSS_std` there reflects spread **across its 6
  trials** (n=6), while CLIP-B/DINO-S/DINO-B's `NSS_std` reflects spread
  **across images** (n=700) -- see
  `outputs/model_comparison_layerwise/comparison_sources.json`. Mixing
  those two kinds of variability into one figure would be misleading.
  Re-bootstrapping every model from its own per-image table (using
  DeiT/SL's already-existing per-image, across-trial-mean values from
  `metrics_by_image_meanacrosstrials.csv`) gives all 4 models an identical
  n=700, image-level resampling procedure. This exact bootstrap recipe
  (seed=42, n_boot=10000, alpha=0.05, image-ID resampling) is not new --
  it is the same convention already used by
  `scripts/stats_three_model_layerwise.py` (`BOOT_SEED=42`, `N_BOOT=10000`,
  `ALPHA=0.05`) and by
  `outputs/clip_attention_b2_distribution/config.json`/`summary.json`
  (`seed=42`, `n_boot=10000`, `alpha=0.05`), so this is a reuse of an
  established repo-wide method, not an invented one. **CI unit: bootstrap
  over the 700 OSIE images** (stated here and should be stated in the
  LaTeX caption/methods text).
- **Figure 2(b)/(c), Appendix 4/5**: group mean = unweighted mean across
  the 12 attributes / 8 features of each one's existing 5-fold
  cross-validation mean (no new probes were fit; this mean-of-existing-
  fold-means was independently cross-checked against
  `outputs/osie_layer_profile_synthesis/layer_profile_table.csv`'s
  `semantic_probe_mean_auprc` / `lowlevel_probe_mean_r2` columns for all
  12 layers -- exact match to 1e-6, see section 5). No CI is drawn for the
  group-mean line in Figure 2b/c (not requested and would require a
  different, image-level resampling of the underlying probe that this
  task explicitly avoids running). Appendix 4/5's per-attribute/per-
  feature shaded bands show **mean +/- 1 SD across the 5 CV folds** --
  this is a *different unit of uncertainty* from Figures 1/2(a)'s
  image-level bootstrap CI, and is labeled as fold-level in this audit
  (state as "shading = +/-1 SD across 5 CV folds" in the appendix caption
  if included in the paper).
- **Figure 3 quantitative panels**: mean + 95% CI for patch counts and
  foreground enrichment are read directly, unmodified, from
  `outputs/clip_attention_b2_distribution/summary.json`
  (`descriptive_per_layer`), which documents its own method as bootstrap
  over n=700 images, seed=42, n_boot=10000, alpha=0.05 (`summary.json`
  top-level fields) -- identical convention to Figures 1-2, confirmed
  programmatically in `verify_figures.py`. The L4-L8/L4-L12/L8-L12
  spatial-correlation matrix uses the existing `same_image_mean` Pearson
  values from `spatial_similarity_descriptive` (point estimates only, no
  CI drawn -- the existing repeated-shuffle robustness analysis in
  `report_revised.md` is the appropriate place for that uncertainty, and
  is out of scope for a compact 3x3 summary panel).

## 4. Changes made vs. existing figures

- Figure 3's attention overlay reuses the existing "shared per-image color
  scale across L4/L8/L12" convention from
  `lib/clip_attention_b2_plots.py::render_per_layer_and_shared_scale_figures`
  (`shared_scale` mode: vmin=0, vmax=max raw attention over L4/L8/L12 for
  that image), but **the colormap was changed from the existing `jet` to
  `viridis`** for perceptual uniformity and colorblind accessibility in
  this new, paper-facing figure. The existing pilot figures
  (`outputs/clip_attention_b2_distribution/figures/*_scale.png`) were not
  touched, overwritten, or regenerated.
- The human-gaze panel uses a separate colormap (`inferno`) and its own
  (unshared) intensity scale, since fixation density and raw attention
  mass are different physical quantities and were never intended to be
  compared on one color scale.
- Figure 1/2's model color palette (Okabe-Ito colorblind-safe: CLIP-B
  black solid, DINO-S blue dashed, DINO-B green dash-dot, DeiT/SL
  vermillion dotted, each with a distinct marker) is a new convention
  introduced for this paper figure set -- it does not exist in any prior
  plotting script in this repo, which used non-colorblind-audited default
  matplotlib/seaborn palettes.
- All titles that existed inside prior figures (e.g. "OSIE 700, healthy",
  trial names, implementation identifiers) are omitted from the image
  itself; per-panel short labels only. Full descriptive titles are left
  for the LaTeX caption (drafts in section 9 below).
- L4/L8/L12 are highlighted with a light vertical band across all figures
  using one shared helper (`common.mark_highlight_layers`), applied
  identically in Figures 1, 2(a-c), 3 is separate (spatial, not
  layer-axis), and Appendix 1-5.

## 9. Draft captions (English)

**Figure 1.** Layer-wise Normalized Scanpath Saliency (NSS) between each
model's attention-derived saliency map and human gaze, across all 12
transformer layers, for CLIP ViT-B/16 (bold) versus DINO ViT-S/16, DINO
ViT-B/16, and DeiT/SL ViT-S/16 (thin lines). CLIP-B shows a characteristic
N-shape layer-wise profile: an early peak (L4), an intermediate trough
(L8), and a late recovery (L12); the other three models do not show this
pattern. Shaded bands are 95% bootstrap CI over the 700 OSIE images (see
Methods); DeiT/SL's per-image value is the mean over its existing 6
training trials.

**Figure 2.** CLIP ViT-B/16's human-gaze alignment does not track what is
linearly decodable from its own hidden representations. (a) Layer-wise
NSS (same data as Figure 1's CLIP-B curve). (b) Layer-wise AUPRC of linear
probes trained to decode 12 OSIE semantic object attributes (bold: mean
across attributes; thin gray: individual attributes), rising through the
early-to-middle layers. (c) Layer-wise out-of-fold R^2 of linear probes
trained to decode 8 low-level visual features (bold: mean across
features; thin gray: individual features), highest in the early layers
and declining thereafter. L4, L8, and L12 are marked in all three panels
for reference against Figure 1/3. The mismatch between panel (a)'s
gaze-alignment trough (L8) and panels (b)/(c)'s probe curves indicates
that "where CLIP's attention concentrates" and "what its hidden layers
make linearly explicit" are at least partially dissociable quantities in
this network; this is not evidence that either process causes the other.

**Figure 3.** Spatial characterization of CLIP ViT-B/16 attention at three
layers with comparable human-gaze alignment along the N-shape profile
(L4, L8, L12). Top: for three representative OSIE images (image ids

hand-picked), the original image, the human gaze density map, and CLIP's
raw `[CLS]`-to-patch attention at L4/L8/L12 (shared color scale per image
across the three layers; white outline marks OSIE-annotated foreground
objects). Bottom: (d) number of patches required to reach 50% of total
attention mass -- L4 spreads over far more patches than L8 or L12; (e)
foreground enrichment (ratio of attention mass on annotated foreground
objects to their image-area share; 1.0 = chance) -- L8's attention is
spatially concentrated but not preferentially on foreground objects,
while L4 and L12 are both foreground-enriched; (f) pairwise spatial
(Pearson) correlation of attention maps across images -- L8 and L12
attend to nearly the same locations, while L4 does not. Error bars/values
in (d)/(e) are bootstrap mean +/- 95% CI over 700 images (same convention

## 10. Figure 3 revision (main-text figure now uses layer-specific color scales)

### Why revised

The original Figure 3 (section 9's caption above) used ONE shared color
scale per representative image (vmin=0, vmax = max raw attention over
L4/L8/L12). Because CLIP-B's raw attention magnitude at L4 is roughly two
orders of magnitude smaller than at L8/L12 (see the per-image colorbar
maxima below), L4 rendered as almost uniformly dark/blank next to L8/L12
under that shared scale -- visually contradicting the figure's own
purpose, which is to show that L4's attention is broadly *spread*, not
that it is *weak*. The bottom row's dataset-level statistics (patch
counts, foreground enrichment, spatial correlation) already supported the
"L4 broad / L8-L12 local" story; the top row simply could not show it.
This revision keeps the bottom row's numbers, data source, and CI method
completely unchanged, and only changes how the top row's attention maps
are color-scaled.

### Representative image(s) used and selection basis

- **Main-text figure** (`figure3_spatial_characterization_revised.*`):
  a single representative image, **1156**.
- **Appendix "additional examples"** figure
  (`appendix/figure_attention_layer_specific_additional_examples.*`): the
  other two, **1159** and **1213**.

All three are the same 3 images used throughout this repo's prior B-2
qualitative figures (`outputs/clip_attention_b2_distribution/figures/
{1156,1159,1213}_{per_layer_scale,shared_scale}.png`), themselves chosen
by the existing pilot's seed=42 draw (`scripts/report_clip_attention_b2_
full700.py`: "Figures reuse the SAME 3 representative images as the pilot
(1156, 1159, 1213 -- chosen by the pilot's seed=42 draw, not
cherry-picked"). No image outside this pre-existing set of 3 was
considered or introduced for this revision.

Before choosing which single image to feature in the main text, all 3
existing pre-existing `*_per_layer_scale.png` figures (i.e., each image's
attention already rendered with per-layer-own color scales, from a prior
B-2 analysis pass, untouched by this task) were visually reviewed:

- **1156** (two people at a pool table): L4 attention visibly washes
  across most of the scene (faces, arms, table edge); L8/L12 show sparse,
  localized hotspots, several at near-identical positions between L8 and
  L12 (e.g., a shared hotspot near the right edge).
- **1159** (three people, indoor): same qualitative pattern -- L4 broad
  wash across all three figures and the background signage; L8/L12
  sparse hotspots, with a shared bright spot in the upper-right corner
  common to both L8 and L12.
- **1213** (surfer): same pattern again -- L4 broad wash including the
  wave/water region; L8/L12 sparse hotspots at the same two positions in
  the upper corners (the two background swimmers) for both L8 and L12.

All 3 images show the same qualitative pattern (L4 broad / L8-L12 local
and mutually similar) under a layer-specific color scale. **1156 was then
kept as the single main-text example because it was the first of the 3 in
this pre-existing, task-independent list** (the task's own stated first
candidate), not because it was the most visually favorable of the 3 --
the other two are shown, unedited, in the appendix specifically so the
main-text choice does not read as if it were the only image that shows
the pattern. This basis is recorded here per the task's requirement to
document the selection reason rather than silently picking the
"cleanest-looking" image.

### Attention-map normalization (top row of the revised figure)

- **Color scale**: layer-specific. For a given image and layer,
  `vmin = 0.0`, `vmax = ` that layer's own raw maximum `[CLS]`-to-patch
  attention value for that image (computed directly from the existing
  38x50-patch cache, no resampling). This is numerically identical to the
  `"per_layer_scale"` mode already implemented in
  `lib/clip_attention_b2_plots.py::render_per_layer_and_shared_scale_figures`
  (reused as the design reference, not re-derived independently) --
  reproducible from the cache alone, with no free parameter to tune.
- **No percentile clipping anywhere.** `vmax` is the exact sample maximum
  of that layer's 38x50 raw attention grid for that image; no percentile
  (e.g. 99th) or manual threshold is applied at L4, L8, or L12. The same
  rule (own raw max, no clipping) is applied identically at all 3 layers,
  so no layer receives special-cased treatment.
- **Non-negativity**: raw attention (post-softmax) is mathematically
  non-negative; this was additionally re-verified at render time (the
  script raises an error if any negative value is encountered) rather
  than assumed.
- **Colormap**: `viridis` (perceptually uniform, colorblind-safe),
  identical across L4/L8/L12 and identical to the original Figure 3.
- **Overlay alpha**: `0.60`, identical across L4/L8/L12 and identical to
  the original Figure 3 (`ATTN_ALPHA` in
  `figure3_spatial_characterization.py`, imported unchanged into the
  revised script rather than redefined).
- **Upsampling**: raw 38x50 attention is bilinearly upsampled to the
  800x600 display resolution for overlay only; all quantitative claims
  (patch counts, enrichment, correlation) are computed upstream on the
  native 38x50 grid, never on this display-only upsampled copy (same
  convention as the original figure).
- **Colorbars**: each of L4/L8/L12 gets its OWN colorbar (not a single
  shared one), with plain decimal tick labels (scientific-notation offset
  text was explicitly disabled, since it visually collided with the panel
  title above it) -- so each panel's actual numeric attention range is
  always visible, never hidden.
- **Foreground contour**: the same OSIE object-mask patch-coverage contour

### sAUC negative-pool caveat (methodological limitation, not a figure defect)

`metrics.py::sauc()`'s shuffled negative pool is drawn from fixations
pooled across **all 700 images, including the evaluated image's own
fixations** (no self-image exclusion) -- confirmed in
`scripts/run_expA_clip_full700.py`'s own docstring ("no self-image
exclusion, metrics.py's internal RandomState(0) untouched") and identical
across all 4 models' extraction scripts (`grep -rn "sauc(" scripts/*.py`
shows no model overrides this). This means sAUC here is best described as
reducing sensitivity to gaze's positional/center bias across the dataset,
**not** as a metric that fully removes or completely controls for it (a
proper self-exclusion sAUC would need each image's own fixations removed
from its own negative pool, which this implementation does not do). The
figure caption uses the accepted phrasing ("sAUC reduces sensitivity to
dataset-level positional bias") and avoids the overclaiming phrasings
("completely removes" / "fully controls for"). See
`METHOD_AUDIT.md` section G for the full sAUC implementation audit
(negative-pool composition, `n_splits=10`, internal `seed=0` -- distinct
from the `seed=42` bootstrap convention used everywhere else in this
figure set).
